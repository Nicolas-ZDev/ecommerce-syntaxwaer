# SyntaxWear — Frontend Static Site

Pequeno site estático de demonstração para uma loja de tênis/sneakers. Inclui layout responsivo com seção de destaque (product grid), categorias, header e footer.

## Estrutura do projeto

- `index.html` — página principal.
- `css/` — estilos principais e componentes:
	- `reset.css`, `variables.css`, `base.css`, `layout.css` (se presente)
	- `components/` — `header.css`, `hero.css`, `product-category.css`, `product-grid.css`, `footer.css`, `newsletter.css`, `panel.css`
- `images/` — ativos (banners, logos, ícones, produtos).

Exemplos de imagens encontradas: `images/banners/hero.jpg`, `images/banners/hero-mobile.jpg`, `images/products/backgroud-grid.png`, `images/logo/Logo.svg`.
